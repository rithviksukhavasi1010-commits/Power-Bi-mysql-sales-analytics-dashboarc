# Sales Analytics Dashboard using SQL Server, MySQL & Power BI

## Project Overview

This project demonstrates the development of an end-to-end Business Intelligence reporting solution using SQL Server, MySQL, and Power BI.

The project focuses on importing, transforming, validating, and visualizing business data to generate actionable insights and KPI-based dashboards for business optimization.

---

# Project Objective

The primary objective of this project is to:
- Build interactive Power BI dashboards for business analysis
- Perform data cleaning and transformation using SQL and Power Query
- Create KPI measures and performance indicators using DAX
- Transition reporting workflow from Test Environment to Production Environment
- Integrate SQL Server and MySQL databases with Power BI
- Publish business reports to Power BI Workspace

# Project Workflow

## Step 1 — Environment Setup
- Installed and configured SQL Server and MySQL Workbench
- Prepared test environment for data processing and reporting

## Step 2 — Data Import and Preparation
- Imported datasets into SQL Server
- Organized relational data tables
- Performed data cleaning and preprocessing
- Prepared transformed datasets for reporting

## Step 3 — SQL Data Transformation
- Applied joins and filtering operations
- Structured business data for analysis
- Validated transformed datasets before reporting

## Step 4 — Power BI Integration
- Connected Power BI Desktop with SQL Server
- Imported transformed datasets into Power BI
- Configured relationships and data models

## Step 5 — KPI and Dashboard Development
- Created DAX measures and KPI indicators
- Developed interactive dashboard pages
- Added filters, KPI cards, and business visuals
- Designed dashboards for operational and financial analysis

## Step 6 — Transition from Test to Production
- Transitioned reporting workflow from Test Environment to Production Environment
- Updated database connections and transformed reports
- Validated production data accuracy

## Step 7 — MySQL Integration
- Installed MySQL Connector
- Imported production data into MySQL database
- Connected Power BI with MySQL data source
- Transitioned reports using Power Query Advanced Editor

## Step 8 — Report Publishing
- Published dashboards to Power BI Workspace
- Verified reporting functionality and accessibility

# Dashboard Metrics

## Page 1 — Demand & Availability Analysis
The first dashboard page focuses on operational demand and supply analysis using KPI indicators such as:
- Average Demand per Day
- Average Availability per Day
- Total Supply Shortage

This dashboard helps identify supply-demand gaps and operational shortages to support business optimization.

## Page 2 — Profit & Loss Analysis
The second dashboard page focuses on financial performance metrics including:
- Total Profit
- Total Loss
- Average Daily Loss

This dashboard helps analyze operational profitability and business losses.
